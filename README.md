# Quizzosaurus

Quiz syntax, intermediate JSON model and parsers for quizzes written in Markdown.

Shared by [Brightspacosaurus](https://github.com/bartvanderwal/brightspacosaurus) (QTI export for Brightspace) and [remark-kroki-a11y](https://github.com/bartvanderwal/remark-kroki-a11y) (interactive quizzes in Docusaurus).

Status: work in progress, nothing published yet.
